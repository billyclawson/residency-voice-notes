# Residency voice questionnaire

A blank, mobile-friendly 21-question form with browser dictation, local autosave, and explicit answer export/share.

No completed answers or personal case documents belong in this repository. Answers remain in the visitor browser until exported. Dictation uses the browser speech service.

Open the hosted page in Safari or Chrome. Keep using the same browser/device to resume. Use Send answers to choose a recipient in the share sheet, or download the text file.
